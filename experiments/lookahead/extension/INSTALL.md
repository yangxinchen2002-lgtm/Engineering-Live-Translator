# ELT 网页字幕跟随

在 ELT.exe 的“课程”页选择“网页视频预读”。语言、翻译 API、术语表、朗读和保存翻译稿由主程序管理。点击启动，连接页中点绿色按钮，然后回课程网页打开扩展并开始跟随。

首次安装：打开 Edge 的 `edge://extensions`，开启开发人员模式，加载正式程序“打开扩展文件夹”按钮打开的目录。已安装过旧实验扩展的用户可以保留原安装目录，重新加载一次后刷新课程页及连接页即可，无需再装第二个扩展。原安装目录由发布同步工具维护，与正式扩展同版本。

扩展权限仅 storage 和指定 TUM / Moodle / Opencast 域及本机服务。无 Cookie、密码、麦克风、调试器、历史、下载或任意网站权限。API Key 留在本机凭据库。原视频播放、暂停、进度和倍速由网站控制；不会自动暂停或刷新课程。

0.6.0 使用紧凑字幕，只显示原文 / 中文和右上角 ×，无内容时隐藏。弹窗“字幕外观”可调宽度（30–100%）、高度上限（64–600 px）和字号（8–48 px）；短句自动收紧，长句可滚动。沿用浅色分组界面和软件图标，可选择 Qwen 0.6B / 1.7B 或 Windows 中文音色，调节朗读、语速、音量和原声比例。修改外观不重启识别或控制视频。

升级已有扩展：在方便刷新课程时，在 edge://extensions 找到 ELT 卡片点击“重新加载”；重新打开 ELT，在“课程”选择 Edge 扩展模式，启动并在新连接页配对；最后手动刷新课程页，再从扩展开始字幕。原安装目录已同步，无需删除、重装或重新选择文件夹。升级过程中不会自动刷新课程。

模型、音色和原声音量设置会应用到当前扩展会话，并回写原程序偏好；未开始时保存供下一次使用。需要先在 ELT 主界面启用中文翻译才能开启朗读。更换本地模型需要准备时间，不能视作无延迟切换。密钥仍只在原程序管理。

关闭正式程序会停止服务和模型。停止后重新启动时，在新连接页重新配对。配对失效时返回主程序点“打开网页连接页”；扩展重新加载后，旧课程页与连接页也需要手动刷新。

当前支持 TUM-Live 和 Moodle 内嵌 Opencast 的已验证点播格式，不支持任意网站、直播、DASH 或受保护媒体。网页音轨无法预读时可切回主程序的应用音频实时字幕。
