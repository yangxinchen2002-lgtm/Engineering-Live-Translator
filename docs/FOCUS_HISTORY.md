# 焦点模式历史回看与返回实时 — 2026-11-03

阶段：M3 追加交互。当前源码已更新，重启已有桌面快捷方式或根目录 `ELT.exe` 即可使用，模型和密钥沿用原配置。

## 使用

1. 启用“置顶字幕窗”和“焦点显示”。默认仍按原规则展示原文/中文、实时原文预览和上推动画。
2. 在字幕正文区域滚动滚轮，或用触控板纵向滚动，进入历史回看。可继续上下滚动；底部出现圆形 **⬇** 按钮，标题提示正在回看历史。回看不受“最近1–12条”的实时卡片数量限制。
3. 回看内容取进入时本次会话最近保留的 **最多128条**原文/中文。新句继续识别、翻译和朗读，历史页面不会被新句拉走；回看中的既有句子仍可补上迟到的中文，按可见句子与偏移量保持阅读位置。
4. 点击底部 **⬇** 返回当前实时字幕，恢复原来设置的焦点位置及自动跟随，按钮隐藏。回看期间的旧动画不会重新播放。若较早句子仍等待有效翻译，返回后仍遵循先前的按原句顺序规则，后句不能抢位。
5. 回看时不自动把新句追加到页面，避免满128条后挤掉正在读的内容；返回实时再进入回看即可读取更新后的最近记录。整节课长期保存仍需独立启用自动翻译稿。

“最近条数”控制实时焦点卡片，不改变历史回看上限。回看状态不写入偏好，下次启动正常进入实时模式；已保存的自定义焦点坐标保持不变。鼠标穿透时不能滚动或点按钮，先用“恢复可编辑”或 Ctrl+Alt+E 恢复输入。

## 实现与生命周期

- `FocusViewport` 保留原有实时卡片/顺序状态，新增独立的 `QScrollArea` 历史页面。历史快照及历史行各最多128项；实时缓存也保持原上限，不创建完整课程的无界列表。
- 回看期间实时模型继续接收更新，焦点渲染在后台直接跟上可显示的当前句，不运行隐藏的上推动画。返回时复用正常的翻译顺序检查，直接定位当前内容。
- 快照只更新已包含句子的修订，不追加新段。正文/中文换行前记录当前可见句子与滚动偏移，布局完成后恢复；换行期间的滚轮输入一起合并，避免被恢复操作撤销。支持角度滚轮及像素增量。
- 进入、返回、清空、新会话、切换显示模式都有明确重置。回看布局用单次Qt定时器，不新增线程/进程；退出时停止待处理布局并释放历史行。字体、颜色和窗口尺寸继续使用现有外观设置。
- 底部按钮平时隐藏；回看时显示在独立底部空间。小窗口下按钮缩小，避免被裁切；极小窗口仍可能只能看到少量文字，可放大窗口阅读。
- 回看不修改原句、翻译状态、字幕revision或保存文件，不发控制命令，不暂停收音/网络/朗读，也不额外调用API或模型。历史行不产生实时焦点绘制计时；`subtitle_history_browsing` 只记录进入/退出状态。焦点的显示指标仍需区别用户主动回看和网络/模型耗时。
- 修复了原焦点重新建立卡片时共享字典被清空的问题：现在保存缓存副本，避免初始化后缓存失效。相应历史、翻译顺序和旧界面回归均验证。

- `app/ui/window.py`：焦点模式操作提示。
