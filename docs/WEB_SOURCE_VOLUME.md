# 内置课程窗口：朗读时原声音量

2026-11-03。复用原软件“朗读时降低原声”的设置，在课程窗口顶部增加同名开关和“原声保留”百分比。退出后重新打开 ELT 即可加载更新；继续使用原 EXE 和桌面快捷方式。

## 使用

顶部的“朗读时降低原声”默认勾选，原声保留默认 20%，范围 10–100%。这是相对于网页原音量的比例：网页原声 65%、保留 20%，中文朗读期间实际原声为 13%。设为 100% 或取消勾选可保留完整原声。

可以在朗读中直接改比例，下一次设置更新生效。只有中文音频真正开始播放才降低原声；模型准备、翻译等待和句间等待不降低。中文读完、暂停中文、关闭朗读或停止字幕后恢复原声。原有中文音量滑块单独控制中文声音。

原声音量设置沿用主界面“朗读”页的偏好，会在下次启动恢复。网页播放器里手动改变原声音量时，以新的手动值作为基准；结束降低后恢复这个新值。原网页已经静音时保持静音。

该次交付先用于 ELT 内置课程窗口；后续0.5.0扩展已接入相同原声控制，见 [EXTENSION_UPDATE.md](EXTENSION_UPDATE.md)。VLC / 应用音频模式仍使用原有 Windows 音源音量管理。

## 实现与生命周期

- `app/web_follow/player.py` 增加顶部开关/数值框，并把真实中文 Audio 的 playing、pause、ended、error 事件关联到课程声音所在的框架；不会把中文播放框架误当作原声音源。
- 共享实现现位于 `extension/source-volume.js`，仅管理实际声音视频元素的 volume，保留基准、避免重复按比例缩小；不改变播放/暂停、位置、倍速或静音状态。原先“播放器完全只读”的约束依用户本次授权放宽到原声音量，播放时钟仍保持只读。
- 中文停止或切换声音框架时立即释放旧音量调整。原生端停止续约超过 1.5 秒时，页内定时器恢复基准音量；页面离开、音源消失也释放。设置错误不停止字幕。后台或页面挂起时定时器执行会受浏览器调度影响，不承诺严格的墙钟恢复期限。
- `/api/playback` 只新增 duck_source 与 source_percent，严格校验类型和范围；不会重建 Whisper、重新翻译、改变 speech_revision 或生成额外 TTS。主界面继续保存既有 speech_duck_source / speech_source_percent，不增加另一套设置文件。
