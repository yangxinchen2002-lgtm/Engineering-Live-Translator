# AI 课程总结设置

[中文](AI_NOTES.md) · [English](AI_NOTES.en.md)

在主界面选择 **工作台 → 存稿 → AI 课程梳理与总结**：

1. 在“总结 API 来源”选择 DeepSeek、OpenAI（GPT）、Anthropic（Claude）或 Google（Gemini）。该选择独立于实时翻译服务。
2. 选择“总结模型”，也可填写所选服务支持且账户有权限使用的文本模型 ID。每个服务分别记住上次选择，不会改变翻译页模型。
3. 点击“设置总结服务密钥”。复用该服务已保存的密钥；密钥保存在本机 Windows 凭据库，不保存进设置或稿件。只有另一服务的密钥时不会自动替换使用。
4. 在主界面“翻译目标语言”选择中文或 English。总结语言跟随此选项，界面语言可以独立选择。
5. 停止字幕后，点击“生成本次 AI 稿”；或勾选“结束翻译后自动生成详细 AI 稿”。首次需选择保存文件夹。
6. 也可点击“选择已有翻译稿整理”，从 UTF-8 TXT 生成总结。无需重做识别或实时翻译。

总结读取本次完整的已确认原文和对应译文，分段生成详细笔记，再生成课程总览。未完成翻译和缺失材料会标注。原文/译文作为材料，不执行其中的模型或工具指令。

任务排队时即固定供应商、模型和语言。处理中会锁定总结服务设置，避免同一份稿件中途切换服务。缺少密钥、权限不足、超时或限流会明确报错，不保存假成功或不完整的 AI 稿；原始翻译稿保留。

AI 总结会向所选 API 发送所需课程文本，单独产生 Token 费用；不会上传原始音频。已报告 Token 和供应商/模型写入总结文件，费用以服务商账单为准。

本次采用四类官方接口的 Mock HTTP/SSE 测试，覆盖实际请求格式、认证头、流式结果和用量，以及中英文界面。没有使用个人密钥或付费请求，不代表已验证所有账户的模型权限、实时网络或总结质量。
