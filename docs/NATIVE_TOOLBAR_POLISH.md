# 课程窗口顶部整理

2026-11-03。用户反馈顶部松散、控件拥挤，重新整理原生工具栏的分组、字体、颜色和尺寸。原 ELT.exe 及桌面快捷方式继续使用；下次重新打开课程窗口即可加载新版。

## 布局

上层为课程操作：返回、刷新、网址、打开课程、TUM-Live、Moodle、开始字幕和停止字幕。开始使用蓝色主按钮，停止使用浅红色；网址随窗口宽度伸缩，也支持回车打开。

下层用三块浅色卡片分组：

- 朗读声音：中文朗读开关、模型、音色。
- 播放设置：基础语速、中文音量。
- 原声平衡：朗读时降低原声、保留比例、读完恢复提示。

宽窗口采用两层布局；小于 1180 个设计像素时，课程按钮和设置自动换行，保留可用的网址输入宽度。标签按内容分配宽度，避免中文被挤成竖排；完整音色名称可在下拉列表和悬停提示中查看。数值范围和保存行为沿用原实现。

## 实现

新增 `app/web_follow/toolbar.py` 集中创建原生控件，复用原 `Player` 的设置、导航和字幕操作。采用现有 WinForms 的布局、绘制与控件，不增加依赖。圆角路径/画笔在使用后释放，缩放时替换旧 Region。`player.py` 继续管理 WebView2、服务连接和朗读生命周期。

没有修改 ASR、翻译、字幕时间、TTS 调度、原声降低算法、密钥或个人稿件。测试只打开独立窗口和本地公开样本，没有操作正在播放的用户课程。
