# 统一音源选择 — 2026-11-04

按用户要求，移除桌面界面原有 VLC / Chrome / Edge / Windows 应用音频分类下拉框，以及仅用于 VLC 分类的打开按钮。音频来源只保留一个具体应用列表、范围提示和刷新按钮。

## 使用

1. 重新打开原 ELT，在“课程”选择“应用音频实时字幕”。
2. 在目标应用播放一下声音，再在“音频来源”中直接选择应用；找不到时点“刷新列表”。列表保留名称、图标、PID 和活动 / 空闲状态，多个实例按 PID 区分。
3. 选择语言后开始字幕。首次枚举显示“正在读取应用音频…”，无可选源时说明如何建立音频会话，不显示空白或自动开始捕获。

捕获仍按应用进程树，可能包含同一应用的多个窗口 / 标签页；不是整个系统，也不是单独标签页。原视频预读（网页 / 本地）入口和控制保持可用。

## 实现与兼容

- 桌面 BackendController 与新偏好默认使用 sessions。MainWindow 不再构建来源分类控件或处理分类切换；具体应用仍通过原身份绑定和启动检查传给原捕获程序。
- 旧 vlc / chrome / edge 来源偏好继续可读取，应用到界面时归一为 sessions，其余语言、外观、翻译、朗读和存稿偏好保留。没有重置用户设置或改动凭据。
- 选中应用仍由 PID / 创建时间核验，重复刷新不会随意更换已选应用；运行中禁用具体应用选择。刷新及切换预读模式使用原异步枚举和生命周期。
- CLI 的旧筛选参数和原生协议没有移除。本次没有改动真实 PCM、ASR、翻译、TTS 或网页文件播放。
