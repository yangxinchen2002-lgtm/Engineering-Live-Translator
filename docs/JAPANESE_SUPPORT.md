# 日语到中文 — 2026-11-03

用户授权在现有软件中增加日语。已接入本机 EXE 所启动的源码；退出并重开即可使用。2026-11-03 后续清理已删除旧的 2026-10-31 便携分卷，当前本机版本保留。原有德英验收报告和 M3 待执行项不因本次新增语言而变为通过。

## 使用

1. 完全退出 ELT，再双击桌面“ELT 工科实时字幕”。
2. 在“课程”页的“原始语言”选 **日语**，选择 VLC / Chrome / Edge 音源。
3. 勾选“启用中文翻译（DeepSeek）”，选择原有的实时预览或整句后翻译，点击“开始字幕”。音频连接就绪后继续播放。
4. 原文仍逐步显示；整句模式在确认的句末标点、VAD 停顿或输入结束后提交翻译。长度上限也可能提前安全分段，不保证每条都是语法完整句。
5. 可继续使用焦点显示、普通多条字幕、存稿和用量统计。启用存稿后，例如生成 `2026-11-03-日语-12分钟.txt`。

Auto 现支持德语、英语、日语，沿用连续高分检测后锁定的策略。知道视频语言时建议固定选择日语；锁定后不会因短暂外语词自动切换，切换课程语言需要停止并重开会话。

CLI 的 `asr-live`、`asr-file`、`translate-live`、`translate-file`、`translate-text` 均可指定 `--language ja`。例如只检查本地日语识别：

```powershell
.\.venv\Scripts\python.exe -m app.main asr-file --input "D:\课程\日语音频.wav" --language ja --seconds 60
```

## 实现与边界

- `app/languages.py` 集中维护语言代码及标签，配置、语言锁、UI、CLI、翻译输入和存稿使用同一列表。没有新增依赖或下载另一份模型。
- 已安装 Faster-Whisper 1.2.1 的 tokenizer 以及本地 large-v3-turbo tokenizer 均支持 `ja`。沿用 `task=transcribe` 本地识别，再由现有 DeepSeek 客户端按 `source_language=ja` 请求简体中文。依据：[对应固定版本的官方 tokenizer](https://github.com/SYSTRAN/faster-whisper/blob/v1.2.1/faster_whisper/tokenizer.py)。
- 日语按模型原有片段拼接，不在字间添加空格；保留模型实际给出的拉丁词空格。确认文本与候选尾部在普通字幕和焦点预览中连续显示，候选仍保留较低视觉权重。
- 官方实现将日语按可解码 Unicode 片段而非空格词分割。因此合并共用结束时间戳/零时长的相邻片段，保留原文与时间范围；日语稳定器不使用德英的 40ms 边界容差。全零时长且无法形成有效时间范围时明确报错，避免静默丢字。没有虚构词时间戳。
- `。！？` 及日语闭引号可触发句末；小数点和原有缩写规则保留。日语的模型片段不按“40 个单词”强制分段，仍有字符上限、VAD 端点和队列容量保护。实时预览的最小长度按模型片段数计数，不视为语言学词数。
- 自选翻译术语表、显式 CLI 课程热词可写 `source_language/language=ja`；日语术语可在相邻助词的句中匹配。默认工程术语表现有内容没有自动扩充为经审核的日语词典，ASR 热词在双语流程中仍默认关闭。
- 文件名固定日语时为“日语”；Auto 按已保存语言组合命名，如“英语+日语”。没有保存原始音频、没有改写旧稿件、没有增加额外计费请求。

## 人工验收

用一段清晰日语视频依次测试两种模式。检查原文不逐字加空格、中文对应当前原文、整句模式句中不发预览请求；暂停恢复后继续识别。启用焦点模式确认未完成原文在中心句下方更新，完成后按原上推动画进入中心；启用存稿后停止，确认文件名含“日语”且正文双语对应。

日语课程的 CER/经分词的 WER、专业术语人工核查和真实延迟仍待专门数据集测试；现有德英质量数字不能套用于日语。既有 30/60 分钟、显示器/DPI 和真实服务异常验收仍待执行。
