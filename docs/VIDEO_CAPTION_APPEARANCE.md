# 紧凑视频字幕与 Windows 系统音色 — 2026-11-04

已接入原 ELT。Edge 扩展更新为 **0.6.0**，原安装目录已同步；内置网页 / 本地视频使用同一字幕布局。应用音频模式的桌面焦点悬窗沿用原外观设置。

## 视频字幕

- 视频画面上只保留原文、中文与右上角 **×**。移除底部状态、诊断计数及大停止按钮；无字幕时隐藏空面板。原文有内容而翻译未就绪时仍显示原文。
- × 只停止 ELT 字幕和朗读，不暂停、跳转或关闭原视频。长字幕滚动时 × 固定在右上角。
- 内置播放器顶部新增 **字幕：宽度 / 高度上限 / 字号**；Edge 弹窗的课程操作下方新增 **字幕外观** 卡片。参数即时应用并沿用原偏好保存。
- 宽度为视频画面宽度的 **30–100%**，高度上限 **64–600 px**，字号 **8–48 px**。默认 92%、180 px、18 px，原文比中文小 2 px，最低 8 px。实际高度还受当前画面 / 视口大小限制。
- 高度是上限，短句自动收紧，不为设置高度留下空白。长句优先两行并自动缩字，超出高度时可滚动查看完整内容，不截掉句尾。
- 浏览器确实阻止中文自动发声时才显示小喇叭按钮，供用户授权；普通运行没有提示占位行。连接和错误仍可在主程序 / 扩展设置页查看。

## Windows 系统音色

原主程序 **朗读 → 模型 → Windows 系统音色**，下方音色框切换为本机已安装的中文声音。本机可用 Microsoft Huihui Desktop（慧慧）。保留 Qwen 0.6B / 1.7B；切回时保留原 Qwen 模型、音色和设备设置。

系统音色既可用于应用音频字幕，也可用于网页 / 本地视频预读。可沿用试听、音量、基础语速、动态追赶和原声调节；视频预读中按原句时间决定是否加速。系统音色不加载 Qwen 或使用 CUDA，不新增云端语音调用。未安装可用中文声音时明确提示，不用假音色替代。

重新打开原 ELT 即可载入主程序更新。Edge 已安装用户需在方便时手动打开 `edge://extensions`，找到 ELT 点 **重新加载**；重新打开 ELT、配对连接页，再手动刷新课程页并开始。无需重新选择扩展目录。更新过程没有自动刷新用户课程。

## 接口与生命周期

共享 `extension/layout.js` 管理字幕 DOM、紧凑样式、尺寸计算和真实 DOM 缩字，扩展及原生观察器调用同一实现。原时间轴、字幕内容、ASR / 翻译 / TTS 队列保持原流程。原生 × 仅接受当前受信文档及 active_frame 的停止消息；旧文档不能停止新会话。

尺寸通过现有认证的 `/api/playback` 与 `/bridge/playback` 传递，使用独立有界整数字段 `caption_width / caption_height / caption_font_size`，沿用 playback_revision 抵御迟到回复。调整外观不重建 ASR、不增加翻译请求、不重建语音。主程序偏好增加带默认值的 web_caption_*，旧设置可读取。

主程序模型列表统一入口，原 web_speech_engine / web_voice 兼容字段继续保存引擎和系统音色；speech_model_size / speech_voice 保留 Qwen 选择。应用音频的系统语音走原独立工作进程和有上限 PCM 协议，使用主 Python 运行环境。SAPI 在工作进程自己的 COM 线程中向 SpMemoryStream 输出 16 kHz / 单声道 / 16-bit PCM，再由原 Qt 播放与变速管线处理；没有临时音频文件。停止或退出按原 Job 回收，界面线程不运行 Speak。

依据：[Microsoft SpVoice 的内存输出](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/ee125640%28v%3Dvs.85%29)、[SpMemoryStream](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/ee125570%28v%3Dvs.85%29)。
