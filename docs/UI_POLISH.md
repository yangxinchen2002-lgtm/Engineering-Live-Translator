## 验收步骤与边界

1. 正常停止字幕、退出 ELT，再双击 `启动ELT.cmd`。已有外观与存稿偏好继续恢复，但不会自动捕获或启用中文。
2. 在“课程”页选择 VLC/Chrome/Edge、语言和时长；“翻译”页找到密钥和术语表；“存稿”页设置目录。验证底部“翻译稿设置”可直接打开存稿页。
3. 主动开始真实课程，检查状态、原文和中文更新；正常停止并确认稿件保存。此次没有替用户发送真实服务请求。
4. 调节字号、焦点、条数和悬窗长宽；用户原先选择的颜色与上推动画应继续生效。主窗口中文区域配色独立于悬窗设置。
5. 缩小主窗口或显示长字幕时可滚动设置/字幕；较矮窗口还有外层滚动，所有内容不保证在任意小尺寸下同时出现。高 DPI、多显示器及各种全屏模式仍按原 M3 计划实机验收。

本次只整理界面，用户延后的本地模型部署与长测未恢复；不自动开展后续扩展。

## 后续修正：字号 / 最近条数显示截断

2026-10-31 用户截图显示数字及“条”字被箭头区挤住。复现时，字号框固定 70 像素，Qt 建议宽度为 79；条数框固定 78，建议为 96，最大值“12 条”文字宽 33，而实际编辑区只有 22。现去掉两处固定宽度，让 Qt 按字体、样式箭头和后缀计算所需宽度，不改数值范围或设置行为。

相关界面回归 **21 通过，1.76 秒**，见 [spinbox-fix-tests.txt](evidence/spinbox-fix-tests.txt)。新增检查覆盖 UI 字体 9/10/12 号、字号 6/10/72、条数 1/5/12，验证实际编辑区足以容纳完整文字。另目视检查 [100%](evidence/spinbox-fix-preview.png)、[150%](evidence/spinbox-fix-scale150.png)、[200%](evidence/spinbox-fix-scale200.png) Qt 离屏缩放预览；不等同于真实多屏混合 DPI 验收。重启 ELT 加载修正，本轮未运行模型、云端请求或长测。
