# 网页扩展 0.5.0：界面与朗读设置同步

当前已更新为 **0.6.0（2026-11-04）**：视频字幕只显示内容及右上角 ×，无内容时隐藏；弹窗新增宽度 / 高度上限 / 字号。原程序朗读区也统一提供 Windows 系统音色。原安装路径已同步，需自行重新加载扩展并刷新课程。实际测试及操作见 [紧凑字幕与系统音色](VIDEO_CAPTION_APPEARANCE.md)。下文保留 0.5.0 当时的功能和测试记录。

2026-11-03。更新现有 ELT 网页扩展，沿用原安装目录及正式程序，没有安装第二个扩展。

## 更新后使用

1. 在方便刷新课程时，打开 Edge 的 `edge://extensions`，找到 ELT 卡片，点击“重新加载”（圆形箭头）。
2. 重新打开 ELT，在“课程 → 网页视频预读”中把“课程播放方式”设为“Edge 网页扩展（兼容）”。启动后，在新的连接页点击“连接网页跟随扩展”。
3. 手动刷新课程页，点击浏览器 ELT 扩展图标，选择语言，再点击“开始字幕”。

已同步 `experiments/lookahead/extension` 与 `app/web_follow/extension`，无需重装或重新选择目录。旧页面保留旧内容脚本，必须在用户方便时手动刷新；本次没有自动重新加载扩展、刷新课程或操作视频。

## 功能

弹窗采用与正式窗口一致的浅色卡片和 ELT 图标，分为课程操作、朗读声音、语速音量、原声平衡。宽420 CSS像素、高约545 CSS像素，无横向溢出。

弹窗支持实时调整中文朗读开关、本地 Qwen 0.6B/1.7B 或系统中文音色、具体音色、基础语速1.00–2.00、中文音量0–100、朗读时降低原声及保留比例10–100。需要先在主界面启用中文翻译才能开启朗读。模型/音色变更仍需准备时间；语速与音量可直接更新。

未开始时保存供下次使用；当前扩展会话运行时应用到现有会话并回写原偏好，不重启 ASR 或重新翻译。主程序继续管理翻译服务、密钥、术语、预读时长、计费和存稿。

朗读实际开始才降低原声，结束/暂停/停止/失联后恢复。扩展与内置窗口共用 `extension/source-volume.js`，按声音视频元素调整；同一文档使用主音轨时钟，跨框架的原声调整根据声音活动与解码状态路由。播放、暂停、位置、倍速和静音状态不由此功能修改。

字幕面板保留原深色双语设计，简化常驻状态与停止按钮；诊断计数可在状态提示中查看。网络异常时保留已准备原文。扩展更新失效时停止自己的定时器和朗读，恢复原声并提示手动刷新。

## 边界与保护

- 权限保持 storage 和原有 TUM/本机域，没有增加 Cookie、历史、麦克风或任意网站权限。API Key 不进入扩展。
- 新 `/bridge/settings`、`/bridge/playback` 复用已有配对验证；变更只允许朗读字段。当前会话必须匹配 owner/session，不可修改另一个内置窗口会话。
- `playback_revision` 防止旧时钟响应覆盖新设置；`speech_revision` 隔离旧音色文件；播放序号避免迟到的播放事件重新压低原声。弹窗一次只保留一个在途请求并合并待发修改；背景进程也限制同时写入数量。
- 音量消息绑定标签、框架及文档身份，旧页面不能影响重新导航后的页面；停止续约时由共享的1.5秒音量租约恢复，浏览器定时器调度限制仍适用。
- 本次没有把内置模式的 Windows 声音匹配自动对时移植到扩展，不宣称所有跨框架播放器的时间轴均已验证。
