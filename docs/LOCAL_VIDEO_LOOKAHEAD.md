# 本地视频预读（2026-11-04）

已接入原 ELT 主程序和内置播放器，继续使用原 `ELT.exe` / 桌面快捷方式。没有新建独立项目，也不需要安装扩展或下载新模型。网页预读和应用音频捕获继续保留。

## 使用

1. 方便时退出并重新打开 ELT，让窗口载入更新。在“课程 → 字幕方式”选择 **视频预读（网页 / 本地）**，播放方式选 **ELT 内置窗口（网页 / 本地）**。
2. 选择课程语言，沿用“翻译”页的 API、模型与中文翻译开关；需要中文声音时沿用“朗读”页的自动朗读、Qwen 模型 / 音色 / 设备。预读秒数仍可设置为 5–30 秒，默认 15 秒。
3. 点击主界面的 **打开本地视频**，选择文件。也可先打开课程窗口，再点击顶部 **本地视频**。播放器不会自动开始播放。
4. 点击播放器顶部 **开始字幕**，会请求原主程序按当前设置启动后台；也可在主界面点 **启动视频预读**。可先等待原文、翻译和语音准备，再自行点击视频的播放按钮。
5. 视频下方原生控件控制播放、暂停和跳转，右上角可调整视频倍速或全屏。原文、中文和朗读按当前视频时间跟随；跳转会取消旧时间段任务，重新准备目标附近内容。软件不会为了等待字幕自动暂停视频。
6. 朗读开关、模型、音色、基础语速、中文音量和“朗读时降低原声”仍在顶部。正常速度能读完时保持基础速度，来不及才加快。Token / 费用估算、历史和可选存稿仍由原主界面管理。
7. **停止字幕**只停止字幕后台和中文声音，文件仍可播放、暂停和拖动。关闭课程窗口或 ELT 才结束该窗口的视频及文件服务。

首次模型准备、跳进度后的重新预读和过长译文仍可能造成等待，未承诺始终提前准备完毕。保存翻译稿沿用原开关和保存地址，不会自动保存原视频或完整课程录音。

## 格式与范围

- 本机实际验证的是单音轨 **H.264 / AAC 的 MP4**，推荐优先使用此格式。
- 文件选择器还提供 M4V、WebM、MOV，以及 MP3、WAV、M4A、OGG。它们能否播放取决于实际编码与本机 WebView2；列入过滤器不代表所有编码均已实测。暂不提供 MKV / AVI 支持或自动转码。
- 当前明确拒绝多音轨本地文件的预读，避免浏览器播放的音轨和识别读取的音轨不同。可改用单音轨文件，或使用原 VLC 应用音频模式自行选择音轨。
- 文件打开后请保持原文件不变。文件被替换、修改、移动、删除或读取失败时会报错，需要重新选择，不会混用前后两份内容。
- 只读取用户明确选择的文件，不扫描媒体库，不接管外部 VLC 播放器时间，也不绕过受保护媒体限制。

## 实现与生命周期

`MainWindow → WebPlayer → Player → LocalMediaHost → 内置 video` 负责文件选择和播放；同一个 `Player` 把实际媒体时钟交给原 `Lab / ASR / CueTranslator / TTS / Presentation`，复用原双语字幕、用量、历史和存稿。没有第二套识别或翻译模型。

- `local_media.py` 的文件服务归播放器所有，独立于字幕后端。绑定 `127.0.0.1` 随机端口，仅接受本次原生选择器注册的一个文件；每次选择更换随机能力地址，旧地址失效。HTTP 请求不接受任意文件路径。
- 页面只得到文件名和临时媒体地址；完整路径与文件身份仅留在本机 Python。Host / Origin 和精确页面地址均校验，不开放 CORS，不记录路径或能力地址。
- 支持真实 HTTP GET / HEAD / Range / 206 / 416，最多 8 个请求线程，每次读 64 KiB。暂停导致读取挂起时不以固定媒体超时打断；切换文件和关闭播放器会主动中断旧连接。
- `Source` 记录设备、文件标识、大小和修改时间。选择、开启解码、读取前后及播放流检查身份，防止后台识别与播放器读到不同文件。解码使用真实 PyAV 混声 / 16 kHz 重采样。
- 本地字幕直接使用同一文件的媒体时间轴，不套用网页独立音轨的 Loopback 对时补偿。现有代际、句段和语音版本校验继续隔离跳转及迟到结果。
- 首次在播放器点“开始字幕”会通过有界子进程消息请求原主界面启动；消息不含密钥。停止识别不撤销文件播放能力，关闭播放器才清理文件服务和子进程。
