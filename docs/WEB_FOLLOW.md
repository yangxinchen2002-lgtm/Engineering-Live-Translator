# 网页视频预读：正式接入与验收

日期：2026-11-03。范围是将已验证的网页预读能力接入现有 ELT 桌面软件，完整 M3/MVP 的长期及质量验收仍待执行。

最新扩展0.5.0已同步分组界面、本地Qwen/系统音色快捷设置、播放中调节和原声保留比例。原安装目录保持有效，更新与验收边界见 [EXTENSION_UPDATE.md](EXTENSION_UPDATE.md)。下文0.4.0及启动前设置的描述保留为早期接入记录。

## 当前内置窗口入口

同一个 ELT 已增加内置课程窗口与 Qwen TTS，由主界面统一设置、开始/停止、计费和存稿；当前默认无需扩展配对。现有扩展方式继续可选。最新步骤与实测见 [INTEGRATED_WEB_PLAYER.md](INTEGRATED_WEB_PLAYER.md)。下文的配对和系统音色说明记录上一版扩展接入方式。

## Edge 兼容方式与原接入记录

继续双击根目录 ELT.exe 或既有桌面快捷方式。“课程 → 字幕方式”可选“应用音频实时字幕”或“网页视频预读”。后者启动后自动打开连接页，设置来自正式界面；点绿色连接按钮，再在原课程页点扩展开始。已有密钥不用重填，不下载新模型。

已安装的旧扩展目录保持有效；重新加载并刷新相关页面后使用当前正式扩展“ELT 网页字幕跟随”0.4.0，不需要安装第二个。主界面优先打开兼容安装目录；新发行包使用 app/web_follow/extension。两份静态扩展资源由 tools/sync_web_extension.py 同步并测试字节一致，不维护两套逻辑。

网页模式使用 Windows 系统中文音色，原音频模式继续使用既有 Qwen 配置。中文默认正常速度，必要时提速、提前读完等待下一句；基础语速和音量在启动前设置。原网页负责暂停、跳转和倍速，正式程序不控制原视频；网页模式桌面暂停按钮与置顶焦点窗停用，字幕位于原播放器。

支持已验证的 TUM-Live 与 Moodle/Opencast 点播格式。未预读到媒体时切回应用音频模式。无新网站、Cookie、密码、麦克风、历史、下载或调试器权限；API Key 不复制给扩展。原音频不上传或默认保存，临时中文 WAV 在正常停止时清理。

## 实现与文件

- app/web_follow：正式的解码、时间轴、整句识别、云翻译、系统语音、HTTP 配对和浏览器静态资源。
- app/web_follow/desktop.py：由 GUI Job 管理的后台进程；有限 CONFIG/STOP 输入，标准字幕/用量/保存事件输出。
- app/web_follow/presentation.py：当前播放时间决定显示，不显示未来内容；未确认上下文只预览、不存稿；跨来源/重建累计用量。
- app/ui/window.py、controller.py、preferences.py：两种模式与共同的密钥、语言、字幕、历史、保存和生命周期。
- app/asr/lease.py：Windows 会话内的识别互斥，退出或强杀后由 OS 释放，防止两份识别模型。
- pyproject.toml、tools/export_source.py：包含网页资源、脚本、第三方许可；原 EXE 动态载入更新模块，无需替换图标或快捷方式。
- experiments/lookahead：兼容导入、历史测试和既有扩展安装路径；旧 EXE 转到正式界面，不再需要独立实验应用。

## 已有验证

环境沿用本机 Windows 11、Python 3.12.10、PySide6 6.8.3、Faster-Whisper 1.2.1、CTranslate2 4.6.0、PyAV 16.0.1；RTX 3500 Ada Laptop GPU。本轮未更换依赖、CUDA 组合或模型。

1. 完整回归 883 通过、2 项跳过（显式音频 smoke 未启用、正式窗口占用快捷键）；最后的关闭保护、源码资源与相关界面补测 88 项通过。结果记录于 artifacts/web-follow-integration/acceptance.json、final-python.xml 和 final-lifecycle.xml。Node 字幕时钟、自然语速、失效、连接与桌面参数测试 35 项通过。测试替身只在测试中使用。
2. 真实正式界面/后台短测（tools/check_web_follow.py）：本机公开英语课程从 20 秒起预读，准备后在显式测试时钟 21 秒处显示真实原文，未来句段未泄露到显示或存稿；没有启动原 Qwen 工作进程。首次准备总计 14.359 秒，包括正式后台启动、加载、解码和识别，不能当作网站延迟 P50/P95。
3. 真实可选翻译稿保存成功，文件名 2026-11-03-英语-0分钟.txt，内容为公开测试原文；测试未调用云翻译，未伪造中文。停止后服务和 GPU 工作 PID 均不存在，临时会话目录为 0。
4. 网页关闭后，原 ASR 工作进程真实完成 CUDA 初始化及静音预热（预热输出丢弃，不作字幕），随后释放。证明识别租约与旧路径启动可继续工作；不是本轮 VLC 音源隔离复测。
5. 真正 Windows 子进程测试通过：GUI OwnerJob 归属、HTTP 配对、正式配置优先、STOP 标记及清理；识别互斥在另一进程被拒绝，释放后可重新获取。此项不需要 GPU 或课程网页。
6. 正式 Qt 界面已离屏渲染检查，并实际用 ELT.exe 打开、在可见窗口选择网页模式且读取系统中文音色；没有用假字幕代替功能。截图是控件/排版验证，不是实机 DPI/全屏验收。新版本网页声音效果和真实网站配对需要用户刷新已安装扩展后验证。

证据：artifacts/web-follow-integration/real-formal-gpu.json、formal-web-mode-final.png、formal-window-live.png、acceptance.json。受限环境的一次补测出现原生线程异常并中断，未计为通过；正常 Windows 环境下复核相关 16 项和上述完整回归均通过，仍如实保留此环境差异。测试输出只记录计数、状态和耗时；未保存媒体签名链接、API Key 或用户课程字幕。显式测试生成的翻译稿使用项目已有的公开课文件。

## 边界和剩余验收

预读目标约 15 秒，句末确认最多扩至本批起点后 30 秒；极长或缺标点内容仍可能按子句降级。处理落后会记录跳过和完整性标志，不保证全文覆盖。翻译或语音迟到可能赶不上原句，视频仍继续。当前字幕按媒体时间显示，桌面历史与可选稿件仅收纳已到播放位置的确认内容。从中途开始、跳转或更换来源保留不完整标志；待确认原文不进入诊断导出。关闭窗口后不再启动已安排的信息查询。

未执行：60 分钟稳定性、全部网站/编码/账户状态、真实课程 WER 与术语质量、新正式版的全屏/混合 DPI 和主观听感回归；网页中文仍为系统音色，没有宣称 Qwen 也完成媒体时钟同步。价格为已有快照估算，以平台账单为准。
