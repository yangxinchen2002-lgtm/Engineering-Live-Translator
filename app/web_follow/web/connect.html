使用提示

首次加载需要等待模型准备。播放、暂停、进度和视频倍速始终由原网页播放器控制。

未发现扩展时，在 ELT 主程序中点击“打开扩展文件夹”，按说明加载后刷新本页。已经安装过旧实验扩展的用户可继续使用原安装目录。

API 密钥保留在本机凭据库。原始音频不上传；字幕和朗读不会让视频自动暂停。
